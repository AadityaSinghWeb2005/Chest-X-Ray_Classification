PROJECT CONTEXT:

This project is a chest X-ray image classification application built using Deep Learning and Transfer Learning.

Dataset:
- COVID-19 Radiography Dataset
- Four classes:
  1. COVID
  2. Normal
  3. Viral Pneumonia
  4. Lung_Opacity
- Total dataset size: 21,165 images
- Dataset was split using stratified splitting:
  - 80% Training
  - 10% Validation
  - 10% Testing

Model:
- DenseNet121
- ImageNet pretrained weights
- Transfer Learning was used
- First, the pretrained DenseNet121 backbone was frozen and the classifier was trained.
- Feature extraction was performed for 10 epochs.
- Then the last DenseNet block was unfrozen and fine-tuning was performed for 10 epochs.
- The final classifier contains Dropout(0.4) followed by a Linear layer mapping DenseNet features to 4 classes.
- Image input size: 224 × 224
- ImageNet normalization was used.

Class imbalance:
- The dataset is imbalanced.
- Class weights were calculated from the training set.
- Weighted CrossEntropyLoss was used during training.

Fine-tuning results:
- Best validation accuracy: 88.00%
- Final test accuracy: 89.84%
- Test Macro Precision: 89.54%
- Test Macro Recall: 91.72%
- Test Macro F1-score: 90.55%

Test-set per-class results:

Application:
- Built using Streamlit.
- Users can upload PNG, JPG, or JPEG chest X-ray images.
- The application performs preprocessing and inference using the fine-tuned DenseNet121 model.
- It displays:
  - Predicted class
